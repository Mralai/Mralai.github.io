# 云服务器部署指南（从 GitHub Pages 迁移 / 或直接落地）

> 什么时候需要：
> - GitHub Pages 在**国内访问不稳**，想要稳定高速；
> - 将来要做**后端 API / 统计 / 评论**等动态功能；
> - 想让下载文件有**大带宽**（Pages 单文件限 100MB，仓库限 2GB）。
>
> 费用：新用户轻量服务器约 **50 ~ 100 元/年（促销）** 起。
> 大陆区域需 **ICP 备案**（免费但耗时 1~2 周）；**香港区域免备案**。

---

## 第 1 步：购买服务器（选型）

| 项目 | 推荐 | 说明 |
| --- | --- | --- |
| 厂商 | 腾讯云 / 阿里云「轻量应用服务器」 | 界面友好、有镜像市场 |
| 区域 | 大陆选你所在省份附近；不想备案选**香港** | 香港免备案且延迟低 |
| 配置 | 2 核 2G 起、带宽 3~5M | 静态站完全够用 |
| 系统 | Ubuntu 22.04 LTS（或选「宝塔面板」镜像） | 见下方方案 A/B |

> 新用户优惠入口：腾讯云「轻量服务器」新用户专享 / 阿里云「99 计划」。
> 学生认证还有低价学生机。

## 第 2 步：ICP 备案（仅大陆服务器需要）

在**云厂商控制台的「备案」入口**提交，全程在线：

1. 准备：身份证、手机号、（可选）幕布照现多为人脸核验；
2. 填写网站信息 —— **网站名称注意**：
   - 个人备案的网站名称不能带「游戏」「新闻」「医疗」等**前置审批行业词**；
   - 你的品牌是「游戏来」，备案时网站名称建议填
     **「XX 的个人作品集 / youxilai 个人主页」** 这类合规名称，
     备案通过后网站显示品牌不受影响（显示文字是页面内容，不是备案名）；
3. 管局审核：一般 5~15 个工作日；**备案期间网站不能解析到大陆服务器访问**；
4. 通过后拿到备案号，页面底部应展示
   「京ICP备XXXXXXXX号-1」样式信息（阿里/腾讯控制台有代码片段）。

## 第 3 步：部署网站

### 方案 A：宝塔面板（新手推荐，5 分钟上线）

1. 服务器控制台 → 重装系统 → 选择「宝塔 Linux 面板」镜像（腾讯云镜像市场里有）；
2. 用控制台给的临时密码登录面板（默认端口 8888，尽快改掉）；
3. 面板 → 软件商店 → 安装 **Nginx**；
4. 网站 → 添加站点 → 填域名 → 根目录设为 `网站根目录`；
5. 本地构建并把产物上传到该目录：

```powershell
# 本地（项目根目录）
npm run build
# 把 dist 目录里的所有文件上传到服务器 /www/wwwroot/<域名>/
# 可用 scp：scp -r dist/* root@服务器IP:/www/wwwroot/<域名>/
```

6. 面板 → SSL → Let's Encrypt 一键签发 HTTPS 证书。

### 方案 B：命令行 Nginx（Ubuntu）

```bash
# 1. 安装
sudo apt update && sudo apt install -y nginx

# 2. 上传站点文件（本机执行）
#    scp -r D:\ALnet\portfolio\dist\* root@你的IP:/var/www/portfolio/

# 3. 使用仓库自带配置
sudo cp deploy/nginx.conf.example /etc/nginx/sites-available/portfolio
sudo nano /etc/nginx/sites-available/portfolio   # 改域名、root 路径
sudo ln -s /etc/nginx/sites-available/portfolio /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 4. HTTPS 证书（域名解析生效后）
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名 -d www.你的域名
```

## 第 4 步：域名解析切到服务器

云平台 DNS 控制台：
- `@` A 记录 → **服务器公网 IP**
- `www` A 记录 → 服务器公网 IP（或 CNAME 到 `@`）

> 切换后约 10 分钟 ~ 24 小时全球生效；生效前旧 Pages 仍可访问。

## 第 5 步：日常更新

**方式 1（简单）**：本地 `npm run build`，把 `dist/` 上传覆盖：
```bash
scp -r dist/* root@IP:/var/www/portfolio/
```

**方式 2（自动）**：让 GitHub Actions 推送代码时自动同步到服务器。
参考 workflow 片段（需要服务器配置 SSH 公钥）：

```yaml
      - name: Deploy to server
        uses: easingthemes/ssh-deploy@main
        with:
          SSH_PRIVATE_KEY: ${{ secrets.SERVER_SSH_KEY }}
          REMOTE_HOST: 你的IP
          REMOTE_USER: root
          SOURCE: dist/
          TARGET: /var/www/portfolio/
```

服务器侧：`ssh-keygen` 生成密钥 → 公钥写入
`~/.ssh/authorized_keys` → 私钥填到仓库 Settings → Secrets and variables → Actions → `SERVER_SSH_KEY`。

## 安全清单（上线后必做）

- [ ] 修改 root 密码 / 禁用密码登录改 SSH 密钥
- [ ] 防火墙只放行 22 / 80 / 443（宝塔面板端口）
- [ ] 打开系统自动更新：`sudo apt update && sudo apt upgrade`
- [ ] Nginx 日志定期清理（`logrotate` 默认已配）
- [ ] 开启 HTTPS（certbot 或宝塔 SSL）
