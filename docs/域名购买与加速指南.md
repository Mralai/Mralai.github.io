# 域名购买与加速指南

> 说明：域名购买需要**你的身份证实名 + 几十到一百多元人民币**，我无法代办，
> 本手册按“照做即可上线”的标准编写。购买前可以先把免费版
> `<用户名>.github.io` 跑起来，域名随时可以后绑。

---

## 第 1 步：在哪里买

| 平台 | 官网 | 特点 |
| --- | --- | --- |
| 阿里云（万网） | https://wanwang.aliyun.com | 国内最大，后续备案/服务器同平台最顺 |
| 腾讯云（DNSPod） | https://dnspod.cloud.tencent.com | 域名便宜、解析快、学生优惠多 |
| Cloudflare | https://www.cloudflare.com | 国外注册商，部分后缀免实名，但国内访问不稳定 |

**建议**：如果将来计划用大陆云服务器（需备案），直接买 **阿里云或腾讯云**，
域名/备案/服务器同账号最省事。

价格参考（新用户常有 1 年优惠价）：
- `.com`：约 60 ~ 90 元/年
- `.cn`：约 29 ~ 39 元/年（仅限中国大陆实名用户）
- `.top / .xyz / .site` 等：约 10 ~ 30 元/年（首年促销常见）

## 第 2 步：挑选域名

- 简短好记：如 `youxilai.cn`、`yxl-dev.com`、`game-lai.cn`；
- 与品牌一致：你的站点署名是「游戏来」，可选 `youxilai`（拼音）；
- 程序员向可选 `.dev`（GitHub 提供免费 https）、`.me`、`.io`；
- 结账时勾选 **隐私保护**（隐藏 whois 个人信息）。

## 第 3 步：实名认证（必做）

1. 控制台 → 域名列表 → 点击「实名认证」；
2. 个人认证：身份证正反面照片 + 人脸识别（一般几分钟 ~ 24 小时通过）；
3. **认证通过前域名无法解析使用**，请先完成再继续。

## 第 4 步：解析到 GitHub Pages（免费方案）

在云平台「域名解析/DNS 管理」添加两条记录：

| 主机记录 | 类型 | 记录值 |
| --- | --- | --- |
| `@` | A | `185.199.108.153` |
| `@` | A | `185.199.109.153` |
| `@` | A | `185.199.110.153` |
| `@` | A | `185.199.111.153` |
| `www` | CNAME | `<你的用户名>.github.io` |

> 也常有人只加一条：`@` CNAME → `<用户名>.github.io`（GitHub 官方推荐 CNAME 方式）。
> 阿里云控制台若提示「@ 记录用 CNAME 需转 DNSPod」之类的限制，就按上面 A 记录填。

## 第 5 步：绑定自定义域名

1. GitHub 仓库 → Settings → Pages → **Custom domain** 填入你的域名（如 `www.youxilai.cn`），点 Save；
2. 勾选 **Enforce HTTPS**（等证书签发，约几分钟 ~ 1 天）；
3. 重复访问几次确认跳转与证书正常。

## 第 6 步：国内访问加速（可选）

`github.io` 在大陆时快时慢。想更稳，三选一：

**方案 A：国内 CDN 套一层（不换服务器、性价比最高）**
- 腾讯云 EdgeOne 或阿里云 CDN，免费/低额度即可覆盖个人站；
- 原理：DNS 先到 CDN 节点（国内），CDN 回源 `github.io`，缓存后访问飞快；
- 需要域名已备案（大陆 CDN 强制要求备案），或用 EdgeOne 香港区域免备案节点。

**方案 B：Cloudflare 免费 CDN**
- 海外节点极快，大陆一般、时快时慢；胜在免费且自带 WAF/缓存；
- 域名 NS 托管到 Cloudflare 后按引导添加记录即可。

**方案 C：换香港服务器（见《云服务器部署指南》）**
- 香港服务器免备案、直连大陆延迟低（30~60ms），适合一劳永逸。

> 备案要求：只要解析回**大陆境内服务器**，就必须先完成 ICP 备案；
> GitHub Pages / 香港服务器 / 海外 CDN 源站均**不需要备案**。
