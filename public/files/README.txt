YXL DevKit DEMO 1.0.0
=====================
这是一个「下载中心」的示例文件包。
正式使用时：
 1) 把真实安装包 / 源码包放入 public/files/ 目录
 2) 在 src/config.ts 的 downloads 数组中登记
    (名称/版本/大小/平台/下载地址)
 3) 大文件请改用 GitHub Releases 托管
    (仓库 Releases 页面上传，地址形如
     https://github.com/<你的账号>/<仓库>/releases/latest/download/<文件>)
 4) 提交并推送即可自动发布 (GitHub Actions)
