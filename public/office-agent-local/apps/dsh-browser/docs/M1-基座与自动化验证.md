## DSH 深绑（当前落地）

| 机制 | 内容 |
|---|---|
| 默认页 | `start_dsh.bat` / 桥 `dsh --url …` → 打开 DSH Web（默认 http://127.0.0.1:3080），`--app-mode` 极简壳 |
| CDP 通道 | 固定 `--remote-debugging-port=9222` + `--remote-allow-origins=*` + `--no-first-run`，独立 profile `~/dsh-browser-profile-thorium`（不与 Chrome/Edge 混用） |
| 控制桥 | `tools/dsh_bridge.py`：`dsh/health/open/list/snap/eval/shot/act/quit/kill`（act 支持 navigate/wait/fill/click/extract/screenshot/eval） |
| 自动发现 | 桥优先用自带 `runtime/thorium-win/thorium.exe`，其次本机 Chrome/Edge；`DSH_BROWSER` 环境变量可指定 |

## 已知边界 / 说明

- 同一浏览器内核同时只允许一个受控实例（profile 锁）；换端口前先 `quit` 或杀残留 thorium.exe。
- PowerShell 传 JSON 参数会吞双引号：act 请走 `tests/` 内 python 直传或 `--actions @文件`（文档待补 stdin 模式）。
- start_dsh.bat 依赖系统 python（控制桥暂未打包为 exe；后续可用 office-assistant 的 PyInstaller 套路把桥打成独立小 exe）。
