# 14 · 来可（Laike）品牌与命名规范

> 定名决议（2026-09-05，用户拍板）：
> **根品牌 = 来可（Laike）** —— 取自用户网名系列「…来」（游戏来/文来/云来）与"来了即用"的寓意。
> 生态命名规则：**来可 + 属性后缀**（产品/服务线任意扩展）。
> 本库现行产品映射：**来可浏览器**（Windows+安卓浏览器）；**来可助手**（office-assistant
> 升级迭代名——本地 DSH 全能力一体封装，见 docs/15）；更名记录见 §6。

## 2. 中文名「来可」

- 读感：来可 = "可以来 / 欢迎来 / 来了就可"，口语亲和；无生僻字。
- 中文商标初查（公开网络线索，非官方全库）：未见明显在先（区别于文来/云来/智来的存量池）；
  正式注册前仍须在中国商标局官网复核（类别：9 计算机软件、42 SaaS、38 通讯、35 广告/销售、
  41 教育娱乐）。注册建议按"来可+产品词"组合或图文中请以增显著性。
- 视觉：建议主字「来」，可用"来"双关"来了/未来"；蓝色主色（延续现有 #1a5cff 蓝）。

## 3. 英文名「Laike」注意（涉外合规）

- **警告**：`Laike` 与海外既有标识冲突风险高——香港 Laike E-Commerce 有在注册商标
  （Justia 可见）、知名音近品牌 LAIKA（动画/时尚/玩具）亦在多个类别布局。
- 涉外发行（Google Play/App Store 全球区、英文 UI）建议**不用 Laike 全拼**作为产品名，
  改用自造英文品牌词（备选：`LaiCore / Laike 图形化/ Laikee / ComeLai` 等，上线前单独
  走 USPTO/EUIPO 检索）。中文名「来可」不受影响（中英分离策略，同国内版/海外版割裂原则）。
