# 07 · 常见问题 FAQ（v3）

## 模型与网络

**Q1 为什么默认连云端 API？完全离线还能用吗？**
产品定位已从"内置本地模型"转为"轻量客户端 + 云端 API 通道"（见 docs/11）。本地能力
（OCR/浏览器自动化/知识库/公文/导出）默认不联网；只有对话需要配置云端 API。
若必须离线：设置→模型来源→本地模型（legacy），把 GGUF 放入应用目录 `models/` 并切换档位。
（v2 整包含模型的离线版归档于仓库外 `office-agent-legacy-archive`。）

**Q2 配置哪个 API？Key 安全吗？**
任何 OpenAI 兼容服务均可（如 DeepSeek：base `api.deepseek.com/v1`、model `deepseek-chat`）。
Key 仅保存在本机 config.json，不随任何上报发出。

**Q3 国内版与海外版有差别吗？**
同一应用两种发行：`OfficeAgentAssistant-CN-Free`（国内免费分发，无订阅/支付/商业引导，
静态剥离订阅代码）；`OfficeAgentAssistant-INTL`（海外商店版，订阅+英文+GDPR）。两者产物与
品牌/账号完全隔离，国内版不提及海外版。

## 使用

**Q4 上传的文件为什么"读不了/答非所问"？**
先确认：上传后文件已自动勾选（附件名出现在输入框上方）。对"总结我上传的文件"类提问，
系统会自动改用摘要型指令（v2.1 修复）；仍异常时请查看文件格式是否受支持：
PDF/.docx/.xlsx/.csv/.txt/.md/.png/.jpg/.jpeg/.bmp/.webp；.doc/.xls 旧格式不支持。
服务重启后上传记录会清空（文档存于内存），请重新上传。

**Q5 知识库怎么用？**
把文档放入应用目录 `kb_data/`（源码运行时为该目录；打包版为 exe 旁 `kb_data`）→
界面左侧"重建索引"。问"知识库有什么文件"会直接列出文件清单。

**Q6 浏览器自动化怎么用？**
需要本机已装 Chrome/Edge。界面 🌐 浏览器 → 填网址打开 → "读取表单字段" →
OCR 图片数据可自动匹配填入；仅连接本机 127.0.0.1 调试口。

**Q7 公文写作/表格统计流程？**
公文：选 📜 公文撰写 + 文种 → 输入要求（可引用知识库）；表格统计：勾选表格文件 →
"表格统计" → 再让 AI 解读/汇总。

## 维护

**Q8 杀毒软件误报怎么办？**
见 docs/03（白名单与规避指南）。未签名程序首次运行提示"未知发布者"属正常。

**Q9 如何更新版本？**
重新解压新发布包替换即可（配置在 config.json、知识库在 kb_data、日志在 workspace——
升级前可备份这三处）。

**Q10 在哪看版本号？**
欢迎语与 ⚙ 设置底部显示（对应 `VERSION.txt`）；欢迎语无版本号说明是旧包。
