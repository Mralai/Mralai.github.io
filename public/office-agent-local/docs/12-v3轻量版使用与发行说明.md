# 12 · v3 轻量版使用与发行说明（API-First 订阅制）

> 对应 [11-商业化与轻量化转型方案](11-商业化与轻量化转型方案.md) 的 M1/M2 落地产物。
> v2 整包（含本地模型，Win7 可用）为 legacy，见 `releases/` 旧 zip 与仓库外 archive。

## 1. 产品形态

| 项 | v3 轻量版 |
|---|---|
| 安装包 | `OfficeAgentAssistant-v3.0/`（onedir，目标 ≤100MB；不含模型/引擎/Python 安装器） |
| 运行环境 | Windows 10/11 x64（legacy v2 包继续覆盖 Win7） |
| 智能后端 | 默认**云端 OpenAI 兼容 API**（DeepSeek 等），设置里配置并"测试连接" |
| 本地能力 | 离线 OCR、浏览器表单自动化、知识库、公文模板、导入导出（全部保留，文件不出域） |
| 订阅 | 设置→"订阅与激活"输入激活码；免费版每日 50 次云端调用 |
| 手机 | 同一界面为 PWA（浏览器"添加到主屏幕"）；云端网关上线后接 App |

## 2. 首启三步

1. 解压 → 双击 `启动办公AI助手(轻量版).bat`（或直接运行 `OfficeAgentAssistant.exe`）；
2. 浏览器自动打开 `http://127.0.0.1:8765`；欢迎语显示版本 `v3.0-M1-20260905`；
3. 右上 ⚙ 设置 → 模型来源选"云端 API" → 填 API 地址/Key/模型名（如
   `api.deepseek.com/v1` / `sk-...` / `deepseek-chat`）→ **测试连接** → 保存并切换。

未配置云端时顶部会显示"云端不可达 → 去设置"横幅；本地能力（OCR/浏览器/KB/模板）不受影响。

## 3. 订阅说明（预发布骨架）

- 激活码格式 `OA3-PRO-XXXXXXXXXXXX`（PRO/TEAM/ENT 三段可推断方案）；
- **演示校验**：正式版由云端订阅中心（M3）在线签发，本机仅存
  `workspace/entitlement.json`（设备号/方案/激活时间/到期/每日用量）；
- 免费档"每日 50 次"为硬限额预留（`config.json → subscription.hard_limit`，默认 false 仅记账）。

## 4. 重新打包（开发者）

```powershell
# 需要：系统 Python 3.10+ 可联网（PyInstaller 5.13+）
apps/office-assistant/packaging/07_pyinstall_light.ps1
# 产物：dist-output\OfficeAgentAssistant-v3.0\
```

## 5. 目录（轻量版运行期）

```
OfficeAgentAssistant-v3.0\
├── OfficeAgentAssistant.exe     ← 主程序（frozen：资源内置 _internal）
├── VERSION.txt
├── 启动办公AI助手(轻量版).bat
├── kb_data\                     ← 知识库：放文档→界面"重建索引"
└── workspace\                   ← 运行期自动生成：logs/uploads/outputs/entitlement.json
```
